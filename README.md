# book-scroll-credo

Embeddable book cover slideshow widget for LibGuides (HTML, CSS, jQuery).

---

### ✅ Features
- Automatically scrolling slideshow
- Clickable book covers (each opens in a new tab)
- Lightweight — only uses HTML, CSS, and jQuery
- Easy to customize (change images, links, timing)
